# Laboratory Bank

Aplicacion bancaria con un backend Spring Boot y un frontend Next.js con Material UI.

## Estructura

```text
backend/    API REST Spring Boot
frontend/   Interfaz web Next.js
```

## Requisitos

- Java 17
- Maven Wrapper incluido en `backend/`
- Node.js 20 o superior y npm
- PostgreSQL 14+ o MySQL 8+

## Configuracion de la base de datos

La configuracion del backend se encuentra en:

```text
backend/src/main/resources/application.properties
```

Se incluyen archivos de ejemplo para inyectar la configuracion sin guardar
credenciales reales en el repositorio:

```text
backend/example.env
frontend/example.env
```

Todas las propiedades deben inyectarse mediante variables de entorno. El archivo
`backend/example.env` contiene la plantilla completa. Como minimo, configure:

```properties
SPRING_APPLICATION_NAME=bank
SERVER_PORT=8080
SPRING_DATASOURCE_URL=...
SPRING_DATASOURCE_USERNAME=...
SPRING_DATASOURCE_PASSWORD=...
SPRING_DATASOURCE_DRIVER_CLASS_NAME=...
SPRING_JPA_DATABASE_PLATFORM=...
```

Para MySQL, defina en `backend/.env` la URL, el driver y el dialecto de MySQL:

```properties
SPRING_DATASOURCE_URL=jdbc:mysql://localhost:3306/lab_bank?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC
SPRING_DATASOURCE_USERNAME=usr_application
SPRING_DATASOURCE_PASSWORD=pass_application
SPRING_DATASOURCE_DRIVER_CLASS_NAME=com.mysql.cj.jdbc.Driver
SPRING_JPA_DATABASE_PLATFORM=org.hibernate.dialect.MySQLDialect
```

No use las credenciales de ejemplo en un ambiente real. Es preferible inyectar los valores mediante variables de entorno o un archivo de configuracion fuera del repositorio.

### Cargar los archivos de ejemplo

Los archivos `example.env` son plantillas y no se cargan automaticamente. Copielos
como archivos locales ignorados por Git y ajuste todos sus valores:

```bash
cp backend/example.env backend/.env
cp frontend/example.env frontend/.env.local
```

En macOS/Linux, exporte las variables del backend antes de iniciarlo:

```bash
set -a
. backend/.env
set +a
```

Para el frontend, Next.js carga automaticamente `frontend/.env.local` al ejecutar
`npm run dev`, `npm run build` o `npm run start`. `BACKEND_URL` es obligatoria y
se usa en `frontend/next.config.ts` para redirigir `/api/backend/*`.

En Windows PowerShell, cargue las variables de forma explicita:

```powershell
$env:SERVER_PORT="8080"
$env:SPRING_DATASOURCE_URL="jdbc:postgresql://localhost:5432/lab_bank"
$env:SPRING_DATASOURCE_USERNAME="usr_application"
$env:SPRING_DATASOURCE_PASSWORD="pass_application"
$env:BACKEND_URL="http://localhost:8080"
```

## Crear la base de datos manualmente

El backend puede actualizar el esquema con Hibernate (`spring.jpa.hibernate.ddl-auto=update`), pero estas instrucciones permiten crear la base y las tablas manualmente.

### PostgreSQL

Conectese como usuario administrador:

```bash
psql -U postgres
```

Ejecute:

```sql
CREATE USER usr_application WITH PASSWORD 'pass_application';
CREATE DATABASE lab_bank OWNER usr_application;
\c lab_bank

CREATE TABLE IF NOT EXISTS customers (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    account_number VARCHAR(255) NOT NULL UNIQUE,
    first_name VARCHAR(50) NOT NULL,
    last_name VARCHAR(50) NOT NULL,
    balance DOUBLE PRECISION NOT NULL CHECK (balance > 0)
);

CREATE TABLE IF NOT EXISTS "transaction" (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    sender_account_number VARCHAR(255) NOT NULL,
    receiver_account_number VARCHAR(255) NOT NULL,
    amount DOUBLE PRECISION NOT NULL CHECK (amount > 0),
    timestamp TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

GRANT CONNECT ON DATABASE lab_bank TO usr_application;
GRANT USAGE ON SCHEMA public TO usr_application;
GRANT SELECT, INSERT, UPDATE, DELETE ON ALL TABLES IN SCHEMA public TO usr_application;
GRANT USAGE, SELECT ON ALL SEQUENCES IN SCHEMA public TO usr_application;
```

Si las tablas ya fueron creadas por Hibernate, ejecute solamente los `GRANT` necesarios.

### MySQL

Conectese como usuario administrador:

```bash
mysql -u root -p
```

Ejecute:

```sql
CREATE DATABASE IF NOT EXISTS lab_bank
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_unicode_ci;

CREATE USER IF NOT EXISTS 'usr_application'@'localhost'
    IDENTIFIED BY 'pass_application';

GRANT ALL PRIVILEGES ON lab_bank.* TO 'usr_application'@'localhost';
FLUSH PRIVILEGES;

USE lab_bank;

CREATE TABLE IF NOT EXISTS customers (
    id BIGINT NOT NULL AUTO_INCREMENT PRIMARY KEY,
    account_number VARCHAR(255) NOT NULL UNIQUE,
    first_name VARCHAR(50) NOT NULL,
    last_name VARCHAR(50) NOT NULL,
    balance DOUBLE NOT NULL,
    CONSTRAINT chk_customers_balance_positive CHECK (balance > 0)
);

CREATE TABLE IF NOT EXISTS `transaction` (
    id BIGINT NOT NULL AUTO_INCREMENT PRIMARY KEY,
    sender_account_number VARCHAR(255) NOT NULL,
    receiver_account_number VARCHAR(255) NOT NULL,
    amount DOUBLE NOT NULL,
    timestamp TIMESTAMP NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT chk_transaction_amount_positive CHECK (amount > 0)
);
```

En MySQL, la tabla `transaction` debe escribirse entre acentos graves porque `TRANSACTION` es una palabra reservada.

## Ejecutar en desarrollo

### 1. Iniciar el backend

Desde la raiz del proyecto:

```bash
cd backend
set -a
. .env
set +a
./mvnw spring-boot:run
```

En Windows:

```bat
cd backend
mvnw.cmd spring-boot:run
```

La API queda disponible en `http://localhost:8080`.

### 2. Iniciar el frontend

En otra terminal:

```bash
cd frontend
npm install
npm run dev
```

La aplicacion queda disponible en `http://localhost:3000`.

El frontend redirige las solicitudes `/api/backend/*` al backend usando la variable
obligatoria `BACKEND_URL` de `frontend/.env.local`.

```bash
npm run dev
```

En Windows PowerShell:

```powershell
$env:BACKEND_URL="http://localhost:8080"; npm run dev
```

## Compilar y ejecutar en produccion

### Backend

```bash
cd backend
set -a
. .env
set +a
./mvnw clean package -DskipTests
set -a
. .env
set +a
java -jar target/backend_bank-0.0.1-SNAPSHOT.jar
```

El backend escucha en el puerto definido por `SERVER_PORT`.

### Frontend

```bash
cd frontend
npm ci
npm run build
npm run start
```

El frontend queda disponible en `http://localhost:3000`.

Para exponerlo en otra interfaz o puerto de Next.js:

```bash
npm run start
```

## API

| Metodo | Ruta | Descripcion |
|---|---|---|
| GET | `/api/customers` | Lista todos los clientes |
| GET | `/api/customers/{id}` | Obtiene un cliente |
| POST | `/api/customers` | Crea un cliente |
| GET | `/api/transactions/{accountNumber}` | Lista movimientos de una cuenta |
| POST | `/api/transactions` | Realiza una transferencia |

Ejemplo de cliente:

```json
{
  "firstName": "Ana",
  "lastName": "Gomez",
  "accountNumber": "100001",
  "balance": 50000
}
```

Ejemplo de transferencia:

```json
{
  "senderAccountNumber": "100001",
  "receiverAccountNumber": "100002",
  "amount": 10000
}
```
